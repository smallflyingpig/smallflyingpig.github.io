# Homepage P0 Optimization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the mobile homepage sidebar blocker and update the bilingual current-role wording without exposing detailed Meituan work or modifying the CV.

**Architecture:** Keep the static HTML/CSS structure. Move sidebar behavior into one dependency-free browser script with a small CommonJS export for Node regression tests; use a mobile-only `mobile-open` class while retaining the existing desktop `collapsed` behavior. Update only the public role sentence in each homepage.

**Tech Stack:** Static HTML, CSS, vanilla JavaScript, Node.js built-in test runner.

## Global Constraints

- Keep the existing desktop sidebar and layout unchanged.
- At viewport widths up to 768px, the sidebar is closed by default.
- Current Meituan work is described only as large-language-model research and development.
- Do not mention internal projects, datasets, pipelines, repositories, metrics, code-pretraining responsibilities, or organizational details.
- Do not edit or regenerate `paper/jiguo_cv.pdf`.
- Do not redesign the homepage, blog, typography, palette, or information architecture.

### Task 1: Mobile sidebar behavior

**Files:**
- Create: `js/sidebar.js`
- Create: `tests/sidebar.test.cjs`
- Modify: `index.html`

- Modify: `css/main.css`

**Interfaces:**
- Produces: `initSidebar(document, window)` and `setSidebarOpen(sidebar, toggle, open)` exported through `module.exports` in Node and initialized automatically in the browser.
- DOM contract: `#sidebar`, `#sidebarToggle`, `#sidebarBackdrop`, and section links inside `#sidebar`.

- [ ] **Step 1: Write failing behavior tests**

Create Node tests that instantiate lightweight event targets and verify:

```javascript
test('mobile sidebar starts closed and opens from the menu button', () => {
  const page = createPage({ mobile: true });
  initSidebar(page.document, page.window);
  assert.equal(page.sidebar.classList.contains('mobile-open'), false);
  assert.equal(page.toggle.getAttribute('aria-expanded'), 'false');
  page.toggle.dispatch('click');
  assert.equal(page.sidebar.classList.contains('mobile-open'), true);
  assert.equal(page.toggle.getAttribute('aria-expanded'), 'true');
});

test('Escape, backdrop, and section links close an open mobile sidebar', () => {
  for (const closeTarget of ['Escape', 'backdrop', 'section']) {
    const page = createPage({ mobile: true });
    initSidebar(page.document, page.window);
    page.toggle.dispatch('click');
    page.closeWith(closeTarget);
    assert.equal(page.sidebar.classList.contains('mobile-open'), false);
    assert.equal(page.toggle.getAttribute('aria-expanded'), 'false');
  }
});

test('desktop menu keeps the existing collapsed sidebar behavior', () => {
  const page = createPage({ mobile: false });
  initSidebar(page.document, page.window);
  assert.equal(page.toggle.getAttribute('aria-expanded'), 'true');
  page.toggle.dispatch('click');
  assert.equal(page.sidebar.classList.contains('collapsed'), true);
});
```

- [ ] **Step 2: Run tests and verify RED**

Run: `node --test tests/sidebar.test.cjs`

Expected: FAIL because `js/sidebar.js` and `initSidebar` do not exist.

- [ ] **Step 3: Implement the minimal behavior**

Implement `js/sidebar.js` so mobile uses `mobile-open`, desktop uses `collapsed`, accessibility state is synchronized, and the three mobile close paths call the same `closeMobileSidebar()` function. Replace each homepage toggle `div` with:

```html
<button class="sidebar-toggle" id="sidebarToggle" type="button"
        aria-controls="sidebar" aria-expanded="false" aria-label="打开页面导航">☰</button>
<button class="sidebar-backdrop" id="sidebarBackdrop" type="button"
        aria-label="关闭页面导航" tabindex="-1"></button>
```

Load the script before `</body>`:

```html
<script src="./js/sidebar.js"></script>
```

In the mobile media query, keep `.sidebar` off-screen by default and reveal only `.sidebar.mobile-open`; display the backdrop only while `mobile-open` is present. Remove the inline `toggleSidebar()` implementations from both homepages.

- [ ] **Step 4: Run tests and verify GREEN**

Run: `node --test tests/sidebar.test.cjs`

Expected: all sidebar behavior tests PASS.
